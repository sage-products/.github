# Getting Help

For a repository question, check its README, existing issues, and support
instructions. Open an issue only when the repository enables that workflow;
include the component, version, expected behavior, and relevant sanitized details.

Greater Goods contributors should use the project's designated company tracker
and team channel for internal work. Use the repository's security reporting
instructions for vulnerabilities. These development repositories are not a
customer support channel; a public product-support destination has not yet been
confirmed here.
