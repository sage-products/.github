# Reporting a Vulnerability

Use **Security → Report a vulnerability** in the affected repository when that
option is available. If it is unavailable, contact a repository maintainer
privately to arrange a confidential report. Do not disclose vulnerabilities,
credentials, customer records, or exploit details in public issues.

Include the affected component/version, the impact, and safe reproduction steps.
Each repository documents its supported versions and any more specific reporting
instructions. Reporting does not authorize testing systems or data you do not own.
