# Sage Products on GitHub

This repository maintains Sage Products' public organization profile and default
contributor resources. Sage Products is a division of Greater Goods LLC.

- `profile/README.md`: public organization overview.
- `CONTRIBUTING.md`: development and review expectations.
- `SECURITY.md`: private vulnerability reporting guidance.
- `SUPPORT.md`: where to ask for help.
- `.github/`: issue and pull request templates.

Repository-specific instructions take precedence over these defaults. Keep this
repository suitable for public access; internal plans and operating records
belong in the designated company systems.
